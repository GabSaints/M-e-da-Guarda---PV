# Origem das imagens — Mãe da Guarda V4

Oito imagens originais foram geradas em 18/11/2026 com o CLI oficial da skill imagegen e gpt-image-2: duas cenas para a página e seis fotos quadradas para o kit social. As cenas são ilustrativas, não registram casos reais. As composições sociais, logos e banners foram finalizados localmente com tipografia e elementos vetoriais. O `.env` e a chave API não fazem parte dos pacotes; confirme os termos de uso aplicáveis à conta antes de publicar.
