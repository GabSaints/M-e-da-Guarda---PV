# Mãe da Guarda — página V4

Página de apresentação para uma nova versão do produto. Identidade em ameixa, rosa queimado, creme e dourado suave, com imagens próprias e layout responsivo. A amostra (`amostra.html`) demonstra uma única tela sem salvar escolhas.

## Proposta do produto

Um web app planejado para apoiar mães e responsáveis quando um filho parece estar com dificuldade de pertencimento na escola. O roteiro terá três movimentos: observar o contexto, conversar sem pressão e combinar um próximo apoio. Uma trilha de sete dias apresenta pequenas ações flexíveis para manter o adulto ativo, sem prometer que a criança se torne popular, faça amizades ou deixe de sofrer bullying.

## Rodar localmente

Nesta pasta, execute `python3 -m http.server 4184` e abra `http://localhost:4184/`.
